# PhotoWatermark - 专业图片水印工具

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Python](https://img.shields.io/badge/python-3.8+-green.svg)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)

一个功能强大、界面友好的Windows桌面应用程序，专为图片水印处理而设计。支持文本和图片水印，提供实时预览、批量处理等专业功能。

## 🌟 核心特性

### 📁 灵活的文件处理
- **多种导入方式**
  - 单张图片：点击按钮选择或直接拖拽
  - 批量导入：一次选择多张图片
  - 文件夹导入：自动扫描文件夹内所有图片
  - 拖拽支持：直接将图片或文件夹拖入应用窗口

- **广泛的格式支持**
  - 输入格式：JPEG (.jpg, .jpeg), PNG (.png), BMP (.bmp), TIFF (.tiff, .tif)
  - 输出格式：JPEG, PNG
  - PNG透明通道完全支持
  - 自动格式检测和转换

### 🎨 强大的水印功能

#### 文本水印
- **内容定制**
  - 自定义水印文本内容

- **视觉效果**

  - 透明度：0-100% 精确控制
  - 阴影效果：可选开启/关闭
  - 描边效果：增强文字可读性

#### 图片水印
- **图片选择**
  - 支持PNG、JPEG等格式作为水印
  - PNG透明通道自动处理
  - 实时图片预览

- **尺寸控制**
  - 缩放比例：0.1x - 3.0x 精确调节
  - 保持原始宽高比
  - 实时缩放预览

- **透明度调节**
  - 0-100% 透明度控制
  - 与原图完美融合

### 📐 精确的位置控制

#### 预设位置
- **九宫格布局**：左上、上中、右上、左中、中心、右中、左下、下中、右下

- **实时预览**：旋转过程中实时显示效果
- **精确控制**：1度精度的角度调节

## 📖 详细使用指南

### 基础操作流程

1. **启动应用程序**
   - 双击 `PhotoWatermark.exe` 或运行 `python main.py`
   - 应用程序将显示主界面

2. **导入图片**
   - 点击左上角"导入图片"按钮选择单张或多张图片
   - 点击"导入文件夹"按钮选择包含图片的文件夹
   - 直接拖拽图片文件或文件夹到应用窗口

3. **选择水印类型**
   - 在右侧面板选择"文本水印"或"图片水印"
   - 根据需要切换不同的水印类型

4. **配置文本水印**
   - 在"水印文本"框中输入要添加的文字
   - 选择字体、调整大小（8-200px）
   - 点击"选择颜色"按钮设置文字颜色
   - 调整透明度滑块（0-100%）
   - 可选开启阴影和描边效果

5. **配置图片水印**
   - 点击"浏览"按钮选择水印图片文件
   - 调整缩放比例（0.1x-3.0x）
   - 设置图片透明度（0-100%）

6. **调整水印位置**
   - 使用九宫格按钮快速定位到预设位置
   - 在预览区域直接拖拽水印到目标位置
   - 使用旋转滑块调整水印角度（-180°到+180°）

7. **设置导出选项**
   - 选择输出格式（JPEG或PNG）
   - 设置JPEG质量（仅JPEG格式）
   - 选择输出文件夹
   - 设置文件命名规则

8. **导出图片**
   - 点击"导出当前图片"处理单张图片
   - 点击"导出所有图片"批量处理所有图片
   - 查看处理进度和结果

### 高级功能

#### 模板管理
- **保存模板**：配置好水印设置后，点击"保存模板"按钮，输入模板名称保存
- **加载模板**：点击"加载模板"按钮，从列表中选择要应用的模板
- **删除模板**：在模板列表中选择不需要的模板进行删除

#### 批量处理技巧
- **统一设置**：为所有图片应用相同的水印设置
- **预览检查**：在批量处理前，先预览几张图片确认效果
- **输出管理**：使用不同的输出文件夹避免文件混乱

#### 性能优化
- **大图片处理**：对于超大图片，应用会自动优化处理速度
- **内存管理**：处理大量图片时，应用会自动管理内存使用
- **错误恢复**：遇到损坏文件时自动跳过并继续处理

## 🛠️ 技术架构

### 核心技术栈
- **GUI框架**：Tkinter - Python标准GUI库
- **图像处理**：Pillow (PIL) - 强大的图像处理库
- **拖拽支持**：tkinterdnd2 - 文件拖拽功能
- **数值计算**：NumPy - 高性能数值计算
- **文件处理**：os, json - 文件和配置管理

### 项目结构
```

├── src/
```

### 核心模块说明

#### WatermarkApp类
- **界面管理**：负责整个GUI界面的创建和管理
- **事件处理**：处理用户交互事件
- **图像处理**：调用Pillow库进行图像操作
- **配置管理**：处理设置的保存和加载

#### 图像处理流程
1. **图像加载**：使用Pillow加载各种格式的图片
2. **水印生成**：根据设置生成文本或图片水印
3. **位置计算**：计算水印在目标图片上的精确位置
4. **图像合成**：将水印与原图进行合成
5. **格式转换**：根据需要转换输出格式
6. **文件保存**：保存处理后的图片到指定位置

## ❓ 常见问题

### Q: 应用程序无法启动？
A: 请确保已安装Python 3.8+和所有依赖包。运行 `pip install -r requirements.txt` 安装依赖。

### Q: 拖拽功能不工作？
A: 确保已安装tkinterdnd2包：`pip install tkinterdnd2`

### Q: 处理大图片时很慢？
A: 这是正常现象。大图片需要更多处理时间，请耐心等待。

### Q: 水印位置不准确？
A: 使用鼠标在预览区域直接拖拽水印到精确位置。

### Q: 如何批量应用不同的水印？
A: 目前版本支持批量应用相同水印。不同水印需要分别处理。
